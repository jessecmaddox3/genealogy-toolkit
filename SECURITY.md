# Security and privacy reports

> **TL;DR:** Do not put personal family information, credentials or sensitive reproduction files in a public issue.

Use GitHub's **Security → Report a vulnerability** in this repository for a private report when that option is available. Otherwise open a public issue containing only a high-level request for a private reporting route. Do not attach the sensitive details there.

Include the release version, affected command and a minimal invented reproduction. This is a personal project with no promised response time or security service level. Local-only operation does not encrypt data or make generated reports safe to publish.
