# Source and asset notes

> **TL;DR:** Owned software, independently invented examples, one generated illustration. No real family records or provider data are distributed.

The code and documentation are offered under the accompanying MIT license. The generated hero, `docs/assets/genealogy-hero.png`, was created with ChatGPT image generation for this project. It depicts a fictional research desk and contains no personal data. It is offered for reuse with this project under the same notice. Its generation brief was: a warm cream, forest teal, terracotta and mustard cut-paper archive desk, linked blank cards, a family-tree motif and a magnifying glass; text “Follow the evidence.” and “Make the story your own.” No names, dates, real documents, geography or portraits.

Demo narratives and mock text records were authored for this release. The `public_domain` and `restricted` values inside the demo illustrate metadata behavior; they are not claims about real archival collections. All demo text is available under the project license. No mock text is represented as an authentic historical document.

The SQLite demo schema is a minimal independently populated compatibility fixture for the supported RootsMagic reader. RootsMagic and FamilySearch names identify interoperability targets; their software, branding, accounts, databases and source content are not distributed, and no affiliation is claimed. Provider-shaped test IDs are invented, not reserved, and are never queried.

The runtime uses the Python standard library. Build/test tools retain their own licenses and are not bundled into the source or wheel. The optional skill calls no model by itself. There are no remote fonts, analytics scripts or trackers in the HTML reader.
